## Environment

Copy `.env.example` when you need Continue with Google. That file is not a full environment catalog.

- `NEXT_PUBLIC_GOOGLE_CLIENT_ID`: Google Identity Services client id. Login and invite signup show Continue with Google only when this is set. Add this dashboard's origin to the Google client.
- `GOOGLE_CLIENT_ID`: optional server-side audience for verifying the ID token during invite signup. Falls back to `NEXT_PUBLIC_GOOGLE_CLIENT_ID`.

Signup still requires an invite link. The Google account email must match the invite.

This project uses [`next/font`](https://nextjs.org/docs/app/building-your-application/optimizing/fonts) to automatically optimize and load [Geist](https://vercel.com/font), a new font family for Vercel.
